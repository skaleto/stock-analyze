# 飞书系统总览文档重构设计

## 目标

将现有纯文字系统总览重构为面向非技术读者也能快速扫读的飞书文档，保留事实完整性，同时显著降低列表密度和阅读负担。

## 信息架构

文档采用“结论先行、图解关系、表格查阅、附录下钻”四层结构：第一屏回答系统是什么、覆盖什么、何时需要人工；正文依次解释总体架构、每日运行、决策与模型、数据源、功能和调度；技术目录和近期变更放在附录。

## 视觉表达

使用四张飞书原生 Mermaid 画板：总体架构、每日流水线、策略与模型关系、自动任务时间轴。数据源、职责分层和 timer 使用表格；只使用一个关键提醒 callout 和少量分栏，不用装饰性卡片堆叠。

## 更新方式

给当前飞书登录用户补充原文档管理权限，使用 XML `overwrite` 原地重构文档。更新后回读目录和全文，确认标题层级、表格、画板 token 与核心事实均存在，并导出至少一张画板预览验证非空。

## 完成标准

- 原链接不变，无重复正式文档。
- 第一屏无需滚动长列表即可理解系统边界和人工动作。
- 至少四张有效画板，图与正文各自承担不同信息。
- 数据源、功能、timer 和风险没有丢失或杜撰。
- 飞书回读无 warning，画板可导出非空预览。
