# K 线与 MACD 联动窗格设计

## 目标

将当前彼此独立的 K 线图和 MACD 图收敛为同一个 `lightweight-charts` 实例的上下窗格，让用户在一次操作中对照价格、成交量与 MACD 动能。

## 交互口径

- 主窗格展示 K 线、可选均线、成交量和策略买卖标记。
- MACD 窗格展示柱状图、DIF 和 DEA，与主窗格共用同一时间轴。
- 在任一窗格拖动、滚轮缩放或使用 `1月 / 3月 / 1年 / 全部` 时，两个窗格始终显示相同日期区间。
- 十字光标跨窗格贯通并定位同一交易日；顶部读数同时更新 OHLC、成交量、DIF、DEA 和 MACD 柱值。
- 关闭 MACD 开关时移除下方窗格，主窗格自动占满图表高度；重新打开时恢复当前时间区间。
- 鼠标离开图表后，读数回到最新交易日。

## 实现设计

`CandlestickChart` 保留一个图表实例。价格、均线、成交量系列位于 pane 0；MACD 柱、DIF 和 DEA 系列位于 pane 1。使用图表库原生 pane 机制代替两个图表实例的事件互相转发，避免缩放回路、日期偏移和重复重绘。

MACD 的 hover 读数不再固定使用最后一个数据点，而是由 K 线十字光标上的日期查找对应 `MacdPoint`。交易标记的 hover 识别和现有配色保持不变。

本次不改动后端接口、K 线数据源、MACD 计算参数或交易决策逻辑。

## 异常与边界

- 无 K 线数据时继续展示现有空状态，不创建任何窗格。
- MACD 计算点数少时仍绘制已有数据，技术解读保留“数据不足”状态。
- 动态切换均线、成交量或 MACD 时，保留用户当前可见的时间区间。
- 移动端仍使用纵向上下窗格，不压缩成并排小图。

## 验收标准

1. 默认打开任一证券时，K 线和 MACD 显示相同的近 1 个月时间区间。
2. 拖动、缩放或切换时间范围不会让 K 线与 MACD 错位。
3. 十字光标在上下窗格定位同一交易日，读数展示当日 K 线与 MACD 数值。
4. MACD 开关可正常移除和恢复下方窗格，时间范围不丢失。
5. 成交标记、均线、成交量和量价分析的现有行为不回归。
6. 前端单测、TypeScript 构建和桌面及移动端页面验证通过，浏览器控制台无新错误。
