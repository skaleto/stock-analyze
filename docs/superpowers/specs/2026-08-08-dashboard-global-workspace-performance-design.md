# Dashboard 全局工作区与加载性能设计

## 背景

当前 Dashboard 把市场切换器放在侧栏顶层，导致“决策总览、模型研究、数据与情报、运行中心”都被误解为某一个市场的子页面。实际上这四个页面描述的是同一个跨市场系统，只有正式模拟策略需要在 A 股与跨境 ETF 之间切换。

客户端的数据请求也以组件生命周期为边界：页面离开后数据即丢失，返回时重新请求；策略详情虽然拆成多个接口，但所谓延迟请求仅延迟一个微任务，仍会在首屏同时竞争服务器资源。ECS 虽有短期响应缓存，却只预热一个情报接口，冷启动和每日数据更新后的首次访问仍明显缓慢。

## 目标

1. 侧栏明确分为全局工作区和模拟策略两类。
2. A 股与跨境 ETF 只在策略工作台分支中出现。
3. 模型研究、数据与情报默认呈现跨市场摘要，按需下钻单市场详情。
4. 运行中心默认呈现全部任务，只在页面内提供“全部 / 仅异常”过滤。
5. 页面切换复用已获取数据，避免 60 秒内重复请求。
6. 策略详情先加载核心资产，再在浏览器空闲时加载研究与治理信息。
7. Dashboard 服务启动后主动预热核心接口，降低首个用户的等待时间。

## 信息架构

```text
Stock Analyze
├── 全局工作区
│   ├── 决策总览
│   ├── 模型研究
│   ├── 数据与情报
│   └── 运行中心
└── 模拟策略
    └── 策略工作台
        ├── 市场：A股 / 跨境ETF
        ├── 策略对比
        ├── 稳健防守
        └── 趋势进攻
```

全局页面 URL 不携带 `market`。旧链接中的 `market` 只作为模型或情报详情的兼容下钻参数，进入全局页面后生成规范化 URL。运行中心旧的市场 scope 归一到 `all`。

## 页面行为

### 决策总览

- 保留现有五段决策链和双市场正式策略矩阵。
- “模型版本”和“结构化情报”节点进入对应全局页，不再硬编码某个市场。
- “正式策略”节点进入用户最近查看的策略市场。

### 模型研究

- 默认只读取系统总览，显示两个市场的候选版本、Champion、验收状态和正式策略采用情况。
- 点击某个市场后才读取 `/api/dashboard/model-research.json?market=...`，在同页展开现有详细研究内容。
- 提供返回跨市场摘要的明确操作，不使用侧栏市场切换器。

### 数据与情报

- 默认只读取系统总览，显示公告目录、PDF、解析、语义抽取、事件、因子和模型采用状态。
- 同页显示两个市场对正式策略的使用状态；单市场详细证据按需加载。
- 不重复大段功能说明，节点上只呈现当前数量、状态、时间和异常。

### 运行中心

- 默认 scope 为 `all`。
- “全部 / 仅异常”放在页面内容区，属于任务过滤，不再伪装成市场导航。

### 策略工作台

- 保留现有策略详情、持仓、净值、K 线和订单布局。
- 在侧栏展开分支顶部提供 A 股 / 跨境 ETF 紧凑分段控件。
- 切换市场时保持当前策略模式（对比、稳健防守或趋势进攻）。

## 数据加载架构

- 引入 TanStack Query 作为统一客户端请求缓存和请求去重层。
- 全局 `QueryClient` 默认 `staleTime=60s`、`gcTime=10min`、失败重试一次、窗口聚焦不自动重拉。
- `useWorkspaceResource` 保持现有调用契约，但底层改为 Query；刷新失败时保留旧快照并标记 stale。
- 系统总览、模型研究、数据情报和运行中心使用共享缓存，页面切换不再丢失结果。
- 策略详情的 overview、performance、portfolio、predictions 立即加载；research、operations、governance 在核心请求完成或浏览器空闲后加载。
- 保留细粒度 API，不重新合并为大接口。

## ECS 预热

新增有界的预热脚本，服务启动后请求：

- summary、system-overview、operations(all)
- 两个市场的 model-research 与 data-intelligence
- 两个市场、两个策略的 overview、performance、portfolio、predictions

研究目录和治理接口不进入启动预热，避免昂贵查询拖慢服务启动。预热失败记录告警但不阻止 Dashboard 服务提供陈旧缓存或实时响应。

## 验收标准

1. 全局页面侧栏不存在市场选择器。
2. 策略工作台展开后可以切换市场，且保持当前策略模式。
3. 规范 URL 中模型研究、数据情报不再默认带 `market`，运行中心不带市场 scope。
4. 从全局页离开并在 60 秒内返回，不产生重复 API 请求且不重新显示整页骨架。
5. 策略详情的非核心接口不会与首批核心接口在同一渲染时刻启动。
6. ECS 服务重启后核心接口均出现缓存命中，页面可正常打开。
7. 桌面和手机视口均无导航重叠、文字溢出或失去当前页状态。

## 回滚

- 前端可回滚到上一版静态资源，不改变后端数据产物。
- 预热脚本与 `ExecStartPost` 可独立移除；Dashboard 主进程不依赖预热成功。
- 路由解析继续兼容旧 URL，回滚不会造成历史链接永久失效。
