# 2026-07 Announcement Benchmark Calibration Archive

This directory preserves the one-off Candidate A/B, Anchor Gold, adjudication,
grading, and handoff materials created during the July 2026 calibration.

These files are audit and QA references only. They are not dependencies of the
daily production path, which is documented in
`docs/announcement-intelligence-runbook.md`.

Do not treat parser success, Candidate agreement, or Anchor completion as proof
that announcement factors improve a prediction model. Production admission is
controlled by deterministic extraction validation, factor support, incremental
model-effect evaluation, and out-of-sample observation.
